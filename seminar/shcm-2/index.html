Khung bot (minh họa)

bot_minh_hoa.py
import random

def score(move, state):
    """Heuristic: càng cao càng tốt. Tự thiết kế phần này."""
    s = 0
    s += 3 * move_points(move, state)      # điểm có ngay
    s += 1 * bonus_value(move, state)      # ưu đãi giảm giá về sau
    s -= 2 * wasted_gems(move, state)      # vượt quá 10 viên
    return s

def choose(state, legal_moves):
    if not legal_moves:
        return None
    best = max(score(m, state) for m in legal_moves)
    return random.choice([m for m in legal_moves if score(m, state) == best])

Đây là pseudo-code để nói ý tưởng. Tên hàm và cấu trúc state thật nằm trong bot mẫu của SDK.
